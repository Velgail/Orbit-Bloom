# Orbit-Bloom（オービット・ブルーム）

シンプルな図形たちが夜空で踊る、やさしめサバイバルシューティング。

**▶ 遊ぶ: https://velgail.github.io/Orbit-Bloom/**

インストール不要・ブラウザだけで動きます（PC / スマホ / タブレット対応）。

## NOVA エディション

倒す、育てる、ボスを突破する。依存ライブラリなしのまま、出撃ごとに武器を組み合わせるサバイバルへ進化しました。

- **経験値と3択強化**：敵が落とす緑の結晶を集めてレベルアップ。拡散弾、連射、攻撃力、援護ドローン、吸引範囲、シールド、ダッシュからビルドを育てます。選択中は時間が止まります。
- **ボス戦**：45秒の通常戦のあと、守護者 BLOOMKEEPER が出現。発射前の弾道予告を読み、HP半分からの第2形態を突破すると次のセクターへ。撃破でHPが1回復します（最大5）。4セクター目以降も番号と難度が上がります。
- **NOVA**：撃破と敵弾への接近でチャージ。100%で発動すると敵弾を消し、全敵に大ダメージ。発動直後は短い無敵時間があります。
- **コンボ**：5秒以内に撃破を続けると、5体ごとにスコア倍率アップ（最大5倍）。被弾するとコンボは終了。
- **読みやすい戦場**：ネオンの自機、射撃、衝撃リング、経験値バー、ボスHP、ビルド表示、出撃結果画面。
- **PC・タッチ両対応**：左下スティック、右下DASH、NOVAボタン。ハイスコアとミュート設定はブラウザに保存されます。

## 操作方法

| 操作 | PC | スマホ / タブレット |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | 左下のバーチャルスティック |
| ダッシュ（短い無敵つき） | Shift / Space | 右下の DASH |
| NOVA | E / NOVA ボタン | NOVA ボタン |
| 強化の選択 | 1 / 2 / 3、カードをクリック | カードをタップ |
| ポーズ | P / Esc / 右上の Ⅱ | 右上の Ⅱ |
| サウンド ON/OFF | M / SOUND ボタン | SOUND ボタン |
| スタート / リトライ | Enter / 出撃ボタン | 出撃ボタン |

ダッシュのクールダウンは自機の黄色いアークとDASHボタンで確認できます。経験値結晶は近づくと吸い寄せられ、8秒後には遠くからでも自動回収されます。強化は出撃ごとにリセットされます。

## ローカルで動かす

ES モジュールを使っているため、`file://` では動きません。HTTP サーバー経由で開いてください:

```bash
git clone https://github.com/Velgail/Orbit-Bloom.git
cd Orbit-Bloom
python3 -m http.server 8000 --directory src
# → http://localhost:8000 を開く
```

ビルド不要・依存ライブラリなし（Vanilla JS + HTML5 Canvas + WebAudio のみ）。

## ブラウザで検証

開発環境に Playwright と Chromium がある場合、HTTPサーバーを起動したまま別のターミナルで実行します。

```bash
node tests/smoke.cjs
```

起動、移動、ダッシュ、ポーズ、経験値回収、強化選択、ドローン、シールド、コンボ、NOVA、ボス戦、エンドレス進行、ハイスコア、スマホのタッチ操作を実ブラウザで確認します。ゲーム本体にPlaywrightは不要です。`ORBIT_TEST_URL` と `CHROMIUM_PATH` で接続先とブラウザを指定できます。
